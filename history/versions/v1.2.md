# v1.2 — EPISODE ENGINE

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/02-episode-pacing.md`

## Frozen rules
- **H-12-001** — 45–90s default mechanics can use Cold Open 0–3 / Orientation 3–12 / Pursuit 12–35 / Mini Payoff 30–50 / Reversal 45–70 / Cliff final 5–15.
- **H-12-002** — Timing must adapt to actual duration, not force padding.
- **H-12-003** — Each episode has one Primary Episode Question.
- **H-12-004** — First 5–10 seconds establish Episode Promise.
- **H-12-005** — Each scene performs at least two functions among plot/character/clue/tension.
- **H-12-006** — Dialogue must perform story function.
- **H-12-007** — Dialogue operates with surface + subtext.
- **H-12-008** — Dialogue pressure: A wants / B wants / hidden intent / leverage.
- **H-12-009** — Use ambiguous truthful answers when fair and useful.
- **H-12-010** — Object curiosity: Plant→Reappear→Change Meaning→Payoff.
- **H-12-011** — Use Visual Question to create curiosity without exposition.
- **H-12-012** — Use Dramatic Irony when information asymmetry helps tension.
- **H-12-013** — Use Mini Loop so short episode contains local reward.
- **H-12-014** — Escalation can move anomaly→danger→personal relevance.
- **H-12-015** — Cut after shock but before full processing only when cliff is earned.
- **H-12-016** — Next episode resolves enough of prior cliff within roughly 0–15s to preserve trust.
- **H-12-017** — First 3 episodes establish premise/core mystery.
- **H-12-018** — First 3 episodes prove engine is not a gimmick.
- **H-12-019** — First 3 episodes provide a meaningful reward.
- **H-12-020** — Run Removal Test: removable episode without state change is filler candidate.
- **H-12-021** — Use Episode Card before dialogue generation.
- **H-12-022** — Core episode formula: Something wrong→tries understand/fix→discovers→discovery worsens→CUT.
