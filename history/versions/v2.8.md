## Frozen rules
- **H-28-001** — Premise must self-generate story.
- **H-28-002** — High concept should be quickly understandable.
- **H-28-003** — High concept should immediately generate questions.
- **H-28-004** — Formula: Protagonist + Unusual Situation + Personal Stake + Curiosity Gap + Hidden Truth Potential.
- **H-28-005** — Five blocks: WHO / WHAT WRONG / WHY MATTER / WHY CAN'T LEAVE / WHAT TRUTH COULD BE.
- **H-28-006** — Create strong Story Lock.
- **H-28-007** — Personalize stakes.
- **H-28-008** — Answer Why This Protagonist.
- **H-28-009** — Answer Why Now.
- **H-28-010** — Use Contradiction Core when useful.
- **H-28-011** — Use Impossible Detail when useful.
- **H-28-012** — Question Stack: Immediate / Personal / Deep.
- **H-28-013** — Curiosity engine types: Identity / Motive / Cause / Relationship / System / Time / Self.
- **H-28-014** — Choose one primary curiosity engine.
- **H-28-015** — Use premise DNA axes and banks.
- **H-28-016** — Use multiple forge formulas for diversity.
- **H-28-017** — Generate diverse batch 5–10 when exploring.
- **H-28-018** — Converge after divergence.
- **H-28-019** — Use Premise Card.
- **H-28-020** — Run One-Line test.
- **H-28-021** — Run And-Then test.
- **H-28-022** — Run Why-Not-Leave test.
- **H-28-023** — Run 30-episode fuel test.
- **H-28-024** — Avoid One-Twist Trap.
- **H-28-025** — Premise engine must survive first reveal.
- **H-28-026** — Identify recurring pressures.
- **H-28-027** — Run Escalation test.
- **H-28-028** — Run Payoff test.
- **H-28-029** — Run Three-Truth test.
- **H-28-030** — Healthy theory space often supports 2–4 plausible interpretations.
- **H-28-031** — Filter for AI production feasibility.
- **H-28-032** — Location can become engine.
- **H-28-033** — Cast can become engine.
- **H-28-034** — Prop can become engine.
- **H-28-035** — Relationship can become engine.
