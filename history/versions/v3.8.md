# v3.8 — STORY PLANNING & DEPENDENCY SCHEDULER

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/13-lint-planning-observability.md`

## Frozen rules
- **H-38-001** — Manage what must happen before what across story and production.
- **H-38-002** — Dependency types: Story Logic / Canon / Information / Character / Artifact / Production / Approval / Validation.
- **H-38-003** — Dependency severity: BLOCKING / HIGH / MEDIUM / LOW.
- **H-38-004** — Task status: NOT_READY / READY / IN_PROGRESS / BLOCKED / REVIEW / DONE / INVALIDATED / CANCELLED.
- **H-38-005** — Task becomes READY when blocking dependencies are satisfied.
- **H-38-006** — Every blocker states what is blocked.
- **H-38-007** — Every blocker states why.
- **H-38-008** — Every blocker states exact unblock action.
- **H-38-009** — Planning units: Decision / Design Task / Artifact / Validation / Production Task.
- **H-38-010** — Task types: DECISION / DESIGN / WRITE / VALIDATE / COMPILE / REVIEW / PRODUCTION / REPAIR / SYNC.
- **H-38-011** — Priority uses Impact × Unlock Value × Risk, not ease.
- **H-38-012** — High-unlock task should outrank low-leverage polish.
- **H-38-013** — Identify Critical Path.
- **H-38-014** — Distinguish story bottleneck from workflow blocker.
- **H-38-015** — Planning horizons: Project / Arc / Episode / Production.
- **H-38-016** — Milestone is state achieved when prerequisite tasks/gates complete.
- **H-38-017** — Quality Gate is scheduler dependency.
- **H-38-018** — Model setup→payoff dependencies.
- **H-38-019** — Track latest safe plant point.
- **H-38-020** — Track design deadline.
- **H-38-021** — Track clue planting deadline.
- **H-38-022** — Track character introduction deadline when required by fairness.
- **H-38-023** — Track trust-build window before betrayal.
- **H-38-024** — Track emotional-development dependency before payoff.
- **H-38-025** — Future arcs depending on open prior truth remain provisional.
- **H-38-026** — Downstream confidence HIGH/MEDIUM/LOW based on upstream stability.
- **H-38-027** — Estimate Waste Risk from uncertainty × downstream effort.
- **H-38-028** — Delay high-effort work built on unstable upstream truth.
- **H-38-029** — Identify safe parallel work.
- **H-38-030** — Parallel work is safe only when shared dependencies stable and sources do not conflict.
- **H-38-031** — Use story/character/mystery/continuity/production/visual/audio workstreams as needed.
- **H-38-032** — Use sync points between workstreams.
- **H-38-033** — Pending sync must resolve before relevant lock.
- **H-38-034** — Upstream change invalidates downstream tasks/artifacts.
- **H-38-035** — Rebuild upstream first in dependency order.
- **H-38-036** — Major mutation produces Impact Task List.
- **H-38-037** — Detect PREMATURE_LOCK_RISK.
- **H-38-038** — Detect DECISION_OVERDUE.
- **H-38-039** — Define earliest useful / latest safe decision window.
- **H-38-040** — Use just-in-time decisions.
- **H-38-041** — Maintain Open Decision Register.
- **H-38-042** — Track Decision Debt.
- **H-38-043** — Allow provisional assumptions but mark dependent work provisional.
- **H-38-044** — Detect dependency cycles.
- **H-38-045** — Break cycle via provisional assumption / branch / scope reduction / function-first lock.
- **H-38-046** — Function-first lock can define required narrative function before exact mechanism.
- **H-38-047** — Placeholder must contain constraints/function, not “something shocking”.
- **H-38-048** — Placeholder expires before affected lock.
- **H-38-049** — Model production resource dependencies.
- **H-38-050** — Character reference precedes costume/scene consistency when needed.
- **H-38-051** — Environment master precedes continuity-sensitive multi-shot scene.
- **H-38-052** — Critical prop reference precedes critical close-up/interaction.
- **H-38-053** — Voice profile precedes batch voice generation when consistency required.
- **H-38-054** — Scene readiness: STORY_READY / ASSET_READY / CONTINUITY_READY / GENERATION_READY.
- **H-38-055** — Generation-ready requires locked script/Scene Pack/refs/props/continuity snapshot.
- **H-38-056** — Distinguish independent shots from sequential shots.
- **H-38-057** — High-continuity shots may require master frame and sequence order.
- **H-38-058** — Failed asset QA re-blocks dependent tasks.
- **H-38-059** — Approval status is dependency where relevant.
- **H-38-060** — Separate story approval from production approval.
- **H-38-061** — Maintain review queue.
- **H-38-062** — Human decisions can be blockers.
- **H-38-063** — AI-resolvable blockers can be handled automatically when safe.
- **H-38-064** — Autonomy profile affects approval routing.
- **H-38-065** — Next Best Action uses unlock/quality/urgency minus waste/dependency risk.
- **H-38-066** — Do not choose easy polish over critical blocker.
- **H-38-067** — User-facing roadmap defaults Now / Next / Later.
- **H-38-068** — Maintain Current Focus.
- **H-38-069** — Use WIP limits to avoid half-finished core decisions everywhere.
- **H-38-070** — Backlogs: Idea / Repair / Experiment / Production.
- **H-38-071** — Prioritize backlog by impact, not age.
- **H-38-072** — Track Story Debt: Logic / Payoff / Decision / Continuity / Polish.
- **H-38-073** — Logic/Decision debt usually resolves earlier than polish debt.
- **H-38-074** — Before producing early episode, run Future Dependency Check for later setup needs.
- **H-38-075** — Whole-series core truth/arc/clue-payoff backbone should be stable before rolling production.
- **H-38-076** — Rolling production can use 3–5 episode batches after backbone lock.
- **H-38-077** — After batch commit update Current State before next batch.
- **H-38-078** — Late change cost rises with production status.
- **H-38-079** — Prefer low-cost late repair when Story Integrity remains intact.
- **H-38-080** — Scheduler is logical order, not calendar by default.
- **H-38-081** — Task size SMALL / MEDIUM / LARGE / XLARGE can guide effort without false precision.
- **H-38-082** — Planning must save more work than it creates.
- **H-38-083** — Model only salient dependencies.
- **H-38-084** — Flags: DEP-001 Missing Dependency / DEP-002 Cycle / DEP-003 Premature Lock / DEP-004 Overdue Decision / DEP-005 Stale Downstream / DEP-006 Blocker Ignored / DEP-007 Unsafe Parallel Work / DEP-008 Production Before Future Setup Lock.
- **H-38-085** — Next Best Action unlocks most value or prevents most rework.
