## Frozen rules
- **H-25-001** — Combine patterns naturally into beats/episodes/arcs/series.
- **H-25-002** — Pattern is not beat.
- **H-25-003** — Pattern is not plot.
- **H-25-004** — Pattern should create decision→consequence→next pattern.
- **H-25-005** — Composition flow: Entry→Pursuit→Complication→Reward→Reorientation→Forward Pull.
- **H-25-006** — Six functions: Hook / Clue / Suspicion / Escalation / Reveal / Cliff.
- **H-25-007** — Tags: [H][C][S][E][R][F].
- **H-25-008** — Compose at beat level.
- **H-25-009** — Compose at episode level.
- **H-25-010** — Compose at arc level.
- **H-25-011** — Compose at series level.
- **H-25-012** — Beat formula: Expected vs Observed = Anomaly→Question.
- **H-25-013** — Episode usually uses roughly 2–4 pattern mechanisms, adjusted to duration.
- **H-25-014** — Avoid Pattern Salad.
- **H-25-015** — Primary Question dominates episode composition.
- **H-25-016** — Use BECAUSE/THEREFORE/BUT causal handoff.
- **H-25-017** — Track pattern lifecycle.
- **H-25-018** — Track series pattern graph when useful.
- **H-25-019** — Compose emotional function, not plot only.
- **H-25-020** — Compose Audience State, not plot only.
- **H-25-021** — Question depth may move What→Who→How→Why→Meaning.
- **H-25-022** — Use consequence/action bridges.
- **H-25-023** — Three-Value Test: curiosity + character + plot.
- **H-25-024** — Track Pattern Debt.
- **H-25-025** — Maintain Curiosity Portfolio.
- **H-25-026** — Use Q priority P1/P2/P3.
- **H-25-027** — Use Surprise Budget.
- **H-25-028** — Use motif chains/signature carefully.
- **H-25-029** — Function First, Pattern Second.
- **H-25-030** — Composition Score max20.
- **H-25-031** — Hard-fail causal/overload violations where defined.
- **H-25-032** — Viewer should experience story, not framework.
- **H-25-033** — Golden Triangle: Curiosity + Causality + Character.
