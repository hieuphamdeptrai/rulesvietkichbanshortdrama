# v2.0 — SERIES BLUEPRINT ENGINE

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/07-premise-blueprint.md`

## Frozen rules
- **H-20-001** — Architect long series before screenplay.
- **H-20-002** — Build backward from Final Truth.
- **H-20-003** — Premise includes WHO / Situation / Core Problem / Curiosity Hook.
- **H-20-004** — Premise should naturally generate at least about 3 meaningful questions.
- **H-20-005** — Core Mystery should be simple and specific.
- **H-20-006** — Core Mystery must support multiple arcs.
- **H-20-007** — Create Final Truth Card before locking clue architecture.
- **H-20-008** — Define Audience False Belief.
- **H-20-009** — Use False Truth before deeper truth when useful.
- **H-20-010** — Use Midpoint Truth that changes objective.
- **H-20-011** — Use 75% Truth/Crash before final convergence when useful.
- **H-20-012** — Use Final Reframe that changes meaning retrospectively.
- **H-20-013** — Truth layers: Surface→False→Midpoint→Near-Final→Core.
- **H-20-014** — Design Mystery Ladder of roughly 5–8 steps when appropriate.
- **H-20-015** — Create 5-arc or other fitting arc structure.
- **H-20-016** — Create Character/Secret/Trust/Suspect maps.
- **H-20-017** — Maintain Twist Bank.
- **H-20-018** — Maintain truth-first Clue Bank.
- **H-20-019** — Maintain Red Herring Bank.
- **H-20-020** — Maintain Payoff Bank.
- **H-20-021** — Maintain Escalation Ladder.
- **H-20-022** — Maintain Resource Map.
- **H-20-023** — Track Points of No Return.
- **H-20-024** — Use Major Event Grid.
- **H-20-025** — Assign Episode Functions.
- **H-20-026** — Create Episode Card before dialogue.
- **H-20-027** — Use THEREFORE/BUT causality.
- **H-20-028** — Run blueprint audits before lock.
- **H-20-029** — Test finale architecture before fully committing Episode 1.
- **H-20-030** — Maintain Knowledge/Trust/Clue/Debt matrices when complexity justifies.
- **H-20-031** — Five-pass review: logic / curiosity / character / retention / payoff.
- **H-20-032** — Pipeline: Premise→Truth→Blueprint→Episode Grid→Episode Plan→Screenplay.
- **H-20-033** — Distinguish Blueprint Lock from flexible zones.
- **H-20-034** — Distance between Ep1 audience belief and final truth defines series journey.
