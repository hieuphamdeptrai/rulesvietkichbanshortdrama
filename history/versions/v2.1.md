# v2.1 — AI WRITING EXECUTION PROTOCOL

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/08-quality-execution.md`

## Frozen rules
- **H-21-001** — AI priority: logic→curiosity→character→escalation→payoff→pacing→dialogue→cinematic polish.
- **H-21-002** — Operational modes: Discovery / Concept / Blueprint / Episode Planning / Screenplay / Audit / Rewrite.
- **H-21-003** — No premature screenplay for canon project.
- **H-21-004** — Samples created before gates must be marked non-canon.
- **H-21-005** — Canon statuses include CANON / PROVISIONAL / IDEA BANK.
- **H-21-006** — Use constraint-first generation.
- **H-21-007** — Separate assumptions from established facts.
- **H-21-008** — For high-leverage choices, generate meaningfully different creative branches when useful.
- **H-21-009** — Separate Writer Truth from Audience Information.
- **H-21-010** — Load character knowledge state before episode/scene writing.
- **H-21-011** — Simulate antagonist response rather than freezing antagonist.
- **H-21-012** — Use THEREFORE/BUT causality in generation.
- **H-21-013** — Generate episode in passes.
- **H-21-014** — Generate screenplay in passes.
- **H-21-015** — Use self-critique after generation.
- **H-21-016** — Use hostile review.
- **H-21-017** — Use Why-Not tests.
- **H-21-018** — Use coincidence audits.
- **H-21-019** — Classify plot-hole category before repair.
- **H-21-020** — Maintain timeline table.
- **H-21-021** — Check scene logic.
- **H-21-022** — Check information duplication.
- **H-21-023** — Prefer subtext to exposition.
- **H-21-024** — Check production feasibility before lock.
- **H-21-025** — Revision priority follows Story OS priorities, not prose polish.
- **H-21-026** — Rewrite report: Problem / Cause / Change / Expected Effect.
- **H-21-027** — Track versioning and ripple.
- **H-21-028** — Protect earlier setups during rewrite.
- **H-21-029** — Avoid silent retcon.
- **H-21-030** — Run anti-cliché/predictability review.
- **H-21-031** — Maintain Decision Log.
- **H-21-032** — Maintain unresolved development questions.
- **H-21-033** — Master loop: Understand→Design→Stress Test→Generate→Score→Critique→Repair→Rescore→Lock.
- **H-21-034** — System may reject flashy idea that weakens higher-priority story layers.
