# v3.6 — STORY COMPILER & ARTIFACT GENERATION PIPELINE

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/12-schema-compiler.md`

## Frozen rules
- **H-36-001** — Compile one authoritative story source into multiple consistent artifacts.
- **H-36-002** — Artifact classes: Development / Writing / Memory / Audit / Production / Handoff.
- **H-36-003** — Every artifact defines Purpose / Inputs / Required Fields / Optional Fields / Output Format / Authority / Invalidation Conditions.
- **H-36-004** — Derived artifact must not become competing source of truth.
- **H-36-005** — Compiler uses source-first behavior.
- **H-36-006** — Compiler must not invent major story fact to fill missing field.
- **H-36-007** — Compilation is distinct from creative generation.
- **H-36-008** — Maintain artifact manifest.
- **H-36-009** — Maintain compiler registry.
- **H-36-010** — Templates define information structure, not creative outcome.
- **H-36-011** — Version templates.
- **H-36-012** — Series Bible compiles from source data.
- **H-36-013** — Character Bible compiles from source data.
- **H-36-014** — Relationship Map compiles from source data.
- **H-36-015** — Mystery Bible/Clue Ledger/Payoff Map compile from source data.
- **H-36-016** — Arc Map and Episode Grid compile from source data.
- **H-36-017** — Support writer/producer/audience/public artifact variants.
- **H-36-018** — Episode Card is writing contract.
- **H-36-019** — Screenplay generation uses compiled Writing Pack.
- **H-36-020** — Writing pipeline: Compile Context→Generate→Extract State Deltas→Validate→Commit.
- **H-36-021** — Screenplay uses stable episode/scene IDs.
- **H-36-022** — Screenplay records source/project/card versions.
- **H-36-023** — Production Brief/Scene Pack/Shot Pack compile from locked script + continuity + assets.
- **H-36-024** — Shot prompt is downstream of approved Shot Pack, not independent story invention.
- **H-36-025** — Compile Character/Location/Prop/Costume/Voice/Dialog/Narration packs only as needed.
- **H-36-026** — Continuity/Audit/Simulation/Context packs are role-specific.
- **H-36-027** — Blind Compile physically excludes spoilers.
- **H-36-028** — Every artifact records version/source refs/status.
- **H-36-029** — Source change marks dependent artifact STALE.
- **H-36-030** — Use dependency graph for smart invalidation.
- **H-36-031** — Use selective compile.
- **H-36-032** — Use just-in-time compile.
- **H-36-033** — Artifact statuses: CURRENT / STALE / DRAFT / APPROVED / SUPERSEDED / INVALID.
- **H-36-034** — Compilation validates source existence/currentness/gates/lint/visibility/version compatibility.
- **H-36-035** — Support partial development compile.
- **H-36-036** — Support strict production compile.
- **H-36-037** — Compiler errors include MISSING_SOURCE / STALE_SOURCE / BROKEN_REFERENCE / VISIBILITY_VIOLATION / VERSION_MISMATCH / LOCK_REQUIRED / TEMPLATE_ERROR / ARTIFACT_STALE / COMPILE_CONFLICT.
- **H-36-038** — Compiler is read-only by default.
- **H-36-039** — Creative generator output is candidate state, not automatic canon.
- **H-36-040** — Flag SCRIPT_SCOPE_DRIFT when screenplay invents major unplanned state change.
- **H-36-041** — Micro creative freedom is allowed if story state unchanged.
- **H-36-042** — Track semantic artifact diff.
- **H-36-043** — Track source entity versions.
- **H-36-044** — Maintain artifact index.
- **H-36-045** — Batch compile only when data ready.
- **H-36-046** — Prefer lazy generation to artifact explosion.
- **H-36-047** — Use fidelity levels Summary / Working / Locked / Execution.
- **H-36-048** — Compiler may compress/expand but not change meaning.
- **H-36-049** — Use glossary/language profile.
- **H-36-050** — Translation preserves power/intimacy/formality/subtext.
- **H-36-051** — Public artifact runs spoiler filter.
- **H-36-052** — Manual edit to derived artifact must sync upstream or be explicit pending override.
- **H-36-053** — Build profiles: Development / Review / Locked / Production / Public.
- **H-36-054** — Character POV pack exposes only allowed knowledge.
- **H-36-055** — Actor/Antagonist/Audience packs are role-specific.
- **H-36-056** — Most artifacts are views over same story graph.
- **H-36-057** — Creative sandbox isolates uncommitted variants.
- **H-36-058** — Pure derived artifact should be reproducible from same source/template.
- **H-36-059** — Gate/Review/Decision packs reduce user information burden.
- **H-36-060** — Bootstrap compiler supports portable resume.
- **H-36-061** — Monolithic export is convenience, not source authority.
- **H-36-062** — Task Environment = System Pack + Story Context Pack + Output Contract.
- **H-36-063** — Hard fail: artifact invents locked facts.
- **H-36-064** — Hard fail: public artifact leaks spoiler.
- **H-36-065** — Hard fail: stale artifact used as current.
- **H-36-066** — Hard fail: conflicting dual authority.
- **H-36-067** — Hard fail: source change does not invalidate downstream.
- **H-36-068** — Hard fail: production pack uses wrong asset version.
