# v3.3 — STORY MEMORY, CONTEXT RETRIEVAL & COMPRESSION ENGINE

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/11-memory-context.md`

## Frozen rules
- **H-33-001** — Repo is long-term memory; context is working memory.
- **H-33-002** — Memory is not context.
- **H-33-003** — Memory pyramid: System / Project Core / Structural / Current State / Local Execution.
- **H-33-004** — Authority: Locked Canon > Current State > Locked Blueprint > Episode Card > Draft > Idea Bank.
- **H-33-005** — Define one source-of-truth per information type.
- **H-33-006** — Memory Address fields: ID/TYPE/VALUE/STATUS/SOURCE/SCOPE/LAST UPDATED/DEPENDENCIES.
- **H-33-007** — Scope: GLOBAL / ARC / EPISODE / SCENE / SHOT.
- **H-33-008** — Lifetime: PERMANENT / LONG / TEMPORARY / EPHEMERAL.
- **H-33-009** — Classes: CANON / STATE / DECISION / CLUE / PROMISE / ISSUE / IDEA / RETIRED / PRODUCTION.
- **H-33-010** — Store current state plus separate event history.
- **H-33-011** — Rejected ideas remain archived but excluded from active retrieval.
- **H-33-012** — Negative Canon records facts/ideas that must not re-enter active story.
- **H-33-013** — Maintain constraint memory.
- **H-33-014** — Separate Story Question from Development Question.
- **H-33-015** — Retrieve by task dependency, not whole repo.
- **H-33-016** — Task classes: Premise / Arc / Episode / Scene / Shot.
- **H-33-017** — Context Pack contains task/project core/current arc/characters/audience/continuity/episode/constraints.
- **H-33-018** — Use Previous/Current/Next retrieval.
- **H-33-019** — Use N-1/N/N+1 episode neighborhood.
- **H-33-020** — Use Series/Arc/Episode/Scene summary layers.
- **H-33-021** — Lossless-required: truth/timeline/knowledge/prop/world.
- **H-33-022** — Lossy compression is allowed for prose where logic is preserved.
- **H-33-023** — Compression must be claim-aware.
- **H-33-024** — Compression must be uncertainty-aware.
- **H-33-025** — Compression must be audience-aware.
- **H-33-026** — Compression must be character-aware.
- **H-33-027** — Maintain writer/audience/character perspectives separately.
- **H-33-028** — Context assembly uses priority/minimization/sufficiency.
- **H-33-029** — Use entity-centric Character/Relationship/Mystery/Prop/Location packs.
- **H-33-030** — Retrieve raw source when exact callback wording/fact matters.
- **H-33-031** — Maintain CURRENT_STATE.md.
- **H-33-032** — Maintain episode/arc compression.
- **H-33-033** — New-session bootstrap loads SYSTEM/PROJECT_STATE/Current Series State/task files.
- **H-33-034** — Maintain BOOTSTRAP.md.
- **H-33-035** — Detect stale context and invalidate it.
- **H-33-036** — Track dependencies like cache invalidation.
- **H-33-037** — Use active/archive separation.
- **H-33-038** — Use branch isolation/merge safety.
- **H-33-039** — Remember decision rationale and story function.
- **H-33-040** — Track open loops/promises/setup dependencies.
- **H-33-041** — Exactness: EXACT / SEMANTIC / FLEXIBLE.
- **H-33-042** — Salience: CRITICAL / HIGH / MED / LOW.
- **H-33-043** — Manage context budget.
- **H-33-044** — Load only relevant modules.
- **H-33-045** — Defend against context pollution.
- **H-33-046** — Role contexts: Architect / Writer / Audience Simulator / Continuity / Production.
- **H-33-047** — Use information firewall and sanitization.
- **H-33-048** — Summary trust: VERIFIED / UNVERIFIED / STALE.
- **H-33-049** — Bind summaries to project version.
- **H-33-050** — Standard flags include MISSING_CONTEXT / STALE_CONTEXT / CONFLICTING_SOURCES.
- **H-33-051** — Standard flags include RETIRED_FACT_LEAK / BRANCH_LEAK / WRITER_TRUTH_LEAK.
- **H-33-052** — Standard flags include OVERLOADED_CONTEXT / INSUFFICIENT_CONTEXT / STATE_STALE / SUMMARY_STALE.
- **H-33-053** — Standard flags include BRANCH_CONTAMINATION / CANON_AMBIGUITY / TRUTH_BELIEF_MERGE / ARCHIVE_LEAK / VERSION_MISMATCH.
- **H-33-054** — Latest does not mean authoritative; status wins.
- **H-33-055** — Validate Context Pack before task.
- **H-33-056** — Use progressive targeted retrieval.
- **H-33-057** — Update CURRENT_STATE after episode/arc/major mutation.
- **H-33-058** — Memory transaction: Read→Modify→Validate→Commit→Refresh summaries.
- **H-33-059** — No partial commit.
- **H-33-060** — Portable Context Packs: project/arc/episode/scene/audit/simulation.
- **H-33-061** — Compression levels C0 RAW / C1 detailed summary / C2 structured state / C3 executive summary.
- **H-33-062** — Causal summary: Event→Meaning→Change.
- **H-33-063** — Memory audit/health score max20.
- **H-33-064** — Maintain Memory Index.
- **H-33-065** — Context Pack Generator targets task such as /write EP18.
- **H-33-066** — Chat is temporary; repo is persistent project brain.
- **H-33-067** — Human-readable Markdown + optional machine-readable mirror.
- **H-33-068** — Production asset lifecycle: DRAFT/REVIEW/APPROVED/REJECTED/SUPERSEDED.
- **H-33-069** — Unknown is valid.
- **H-33-070** — Assumptions are not canon.
- **H-33-071** — Promotion can move IDEA→PROVISIONAL→APPROVED→LOCKED or RETIRED.
- **H-33-072** — Use smallest complete context.
- **H-33-073** — Compress prose, not logic.
- **H-33-074** — Never pass secrets to roles that should not know them.
- **H-33-075** — Story should outlive chat.
