## Frozen rules
- **H-27-001** — Mutate exact weak variable while preserving strengths.
- **H-27-002** — Mutation frame: Preserve / Mutate / Problem / Target Effect.
- **H-27-003** — Mutation scope: Micro / Episode / Arc / Character / Core.
- **H-27-004** — Minimum-Change Rule: prefer smallest change that fixes root cause.
- **H-27-005** — Diagnose symptom→cause→target before alternatives.
- **H-27-006** — Mutation axes: WHO / WHAT / WHY / HOW / WHEN / WHERE / RELATIONSHIP / KNOWLEDGE / COST / MEANING.
- **H-27-007** — Locks: LOCKED / SOFT / OPEN.
- **H-27-008** — Use Mutation Card.
- **H-27-009** — Generate Conservative option when useful.
- **H-27-010** — Generate Balanced option when useful.
- **H-27-011** — Generate Bold option when useful.
- **H-27-012** — Anti-Synonym: alternatives differ structurally, not wording only.
- **H-27-013** — Preserve narrative function where required.
- **H-27-014** — Preserve character function where required.
- **H-27-015** — Preserve emotion where required.
