# v1.3 — TWIST ENGINE

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/03-twist-hook-cliff.md`

## Frozen rules
- **H-13-001** — Twist = Surprise + Inevitability + Consequence.
- **H-13-002** — Core mechanism: Audience Belief→Contradiction→New Interpretation.
- **H-13-003** — Twist types include Identity / Motive / Relationship / Cause / Timeline / POV / Object / Meaning.
- **H-13-004** — Twist ladder can deepen information→identity/relationship→motive→cause/timeline→meaning.
- **H-13-005** — Major twist normally requires 2–3 fair footprints.
- **H-13-006** — Use double-meaning plants.
- **H-13-007** — Use Reaction Clue.
- **H-13-008** — Use Absence Clue.
- **H-13-009** — Use Negative Evidence.
- **H-13-010** — Red herring should be a true fact leading to wrong conclusion.
- **H-13-011** — Red herring ideally has secondary payoff.
- **H-13-012** — POV must remain fair.
- **H-13-013** — Do not hide what viewpoint character unmistakably sees solely to protect twist.
- **H-13-014** — False Reveal contains partial truth, not arbitrary fabrication.
- **H-13-015** — Double Twist is high-intensity and should be sparse.
- **H-13-016** — Delayed Twist is high-intensity and should be sparse.
- **H-13-017** — Cascade Twist is high-intensity and should be sparse.
- **H-13-018** — Prefer character-driven twist that changes choice or relationship.
- **H-13-019** — Impossible Fact must later receive logical supported explanation.
- **H-13-020** — Twist Matrix: WHO / WHY / WHAT / WHEN / WHERE / HOW / RELATIONSHIP / MEANING.
- **H-13-021** — Twist Score max16 across Surprise/Logic/Foreshadow/Consequence/Character/Mystery/Rewatch/Simplicity.
- **H-13-022** — Prefer simplest explanation that preserves mystery/emotion.
- **H-13-023** — Emotional twist should create both recognition and reinterpretation.
- **H-13-024** — Golden: let audience infer wrongly from true facts.
