# v2.2 — QUALITY CONTROL & RED-TEAM ENGINE

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/08-quality-execution.md`

## Frozen rules
- **H-22-001** — Writer Mode cannot self-approve major output.
- **H-22-002** — Use independent Red-Team pass.
- **H-22-003** — Red-Team lenses: Bored Viewer / Smart Viewer / Skeptic / Mystery Fan / Character Viewer / Continuity Editor / Producer.
- **H-22-004** — Run hostile-viewer objections.
- **H-22-005** — Attack core logic.
- **H-22-006** — Ask whether an obvious solution invalidates plot.
- **H-22-007** — Check character competence.
- **H-22-008** — Check POV fairness.
- **H-22-009** — Audit continuity.
- **H-22-010** — Audit mystery fairness.
- **H-22-011** — Test predictability around 25%.
- **H-22-012** — Test predictability around 50%.
- **H-22-013** — Test predictability around 75%.
- **H-22-014** — Attack randomness.
- **H-22-015** — Attack necessity.
- **H-22-016** — Attack consequence.
- **H-22-017** — Attack repetition.
- **H-22-018** — Attack hook separately.
- **H-22-019** — Attack cliff separately.
- **H-22-020** — Inspect middle retention.
- **H-22-021** — Use deletion tests.
- **H-22-022** — Production/AI risk: LOW / MED / HIGH.
- **H-22-023** — Audit Payoff Debt.
- **H-22-024** — Audit Chekhov setups.
- **H-22-025** — Run finale-specific audit.
- **H-22-026** — Distinguish curiosity from confusion.
- **H-22-027** — Healthy mystery often supports 2–4 plausible theories.
- **H-22-028** — No deus ex solution.
- **H-22-029** — Scores require evidence.
- **H-22-030** — Use three-pass red team for high-value milestone.
- **H-22-031** — Severity: Critical / Major / Moderate / Minor.
- **H-22-032** — Issue report records exact problem/evidence/impact/repair route.
- **H-22-033** — Fix priority: core logic→character→curiosity→payoff→production→polish.
- **H-22-034** — After repair run regression test.
- **H-22-035** — After repair re-score.
- **H-22-036** — Acceptance thresholds are gate-specific.
- **H-22-037** — Fix what loses curiosity, trust or emotion first.
