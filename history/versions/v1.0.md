# v1.0 — SHORT DRAMA CURIOSITY SYSTEM

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/01-curiosity-core.md`

## Frozen rules
- **H-10-001** — Core question: after this scene/episode, does the audience need to know what happens next?
- **H-10-002** — Always leave at least one meaningful unanswered question.
- **H-10-003** — Curiosity question must be specific enough for audience theory, not vague suspense.
- **H-10-004** — Reveal something while opening something larger.
- **H-10-005** — Answer should be more interesting than the question that created it.
- **H-10-006** — Every episode changes audience understanding.
- **H-10-007** — Use Information Gap A + ?.
- **H-10-008** — Use Question Chain Q1→A1/Q2→A2/Q3 rather than endless withholding.
- **H-10-009** — Use Plant→Delay→Payoff.
- **H-10-010** — Meaningful setup needs a planned function and return.
- **H-10-011** — A False Answer may be factually true but wrongly interpreted.
- **H-10-012** — Prefer audience misinterpretation of true facts over fabricated evidence.
- **H-10-013** — Escalation deepens mystery rather than repeats the same question louder.
- **H-10-014** — Character secret model: WANT / REAL WANT / SECRET / FEAR / LEVERAGE.
- **H-10-015** — Cliffhanger creates an urgent specific next question.
- **H-10-016** — Cliffhanger should change story state, not merely interrupt a scene.
- **H-10-017** — Twist adds meaning without breaking established logic.
- **H-10-018** — Mystery layers: Micro / Mid / Core.
- **H-10-019** — Episode five-beat: Hook→Pursuit→Reveal→Reversal→Cliff.
- **H-10-020** — Episode shorthand: Hook→Search→Answer→But→CUT.
- **H-10-021** — Use “1 trả – 2 mở” when useful, without question overload.
- **H-10-022** — Audience must have enough evidence to theorize.
- **H-10-023** — Confusion is not curiosity.
- **H-10-024** — Maintain Mystery Ledger for long series.
- **H-10-025** — Maintain Character Knowledge Map.
- **H-10-026** — Ban random twist.
- **H-10-027** — Ban making characters stupid for plot convenience.
- **H-10-028** — Ban camera/POV cheat.
- **H-10-029** — Ban no-payoff mystery.
- **H-10-030** — Ban fake cliff.
- **H-10-031** — Ban introducing a new explainer character to solve everything.
- **H-10-032** — Ban shock that does not change story.
- **H-10-033** — Curiosity Score max20 across Hook/InfoGap/Progress/Reveal/Reversal/Escalation/Cliff/Logic/Character/Next Episode Desire.
- **H-10-034** — Not every episode needs a twist; every episode needs progress.
