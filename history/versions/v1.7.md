# v1.7 — ESCALATION & CONFLICT ENGINE

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/06-escalation-payoff.md`

## Frozen rules
- **H-17-001** — Mystery must create consequence, choice, loss, danger, conflict or time pressure.
- **H-17-002** — Escalation axes: Danger / Cost / Time / Information / Relationship / Moral.
- **H-17-003** — Use Price of Knowledge: truth increasingly costs something.
- **H-17-004** — Deadlines must emerge from story logic.
- **H-17-005** — Secret Compression increases pressure as more parties approach truth.
- **H-17-006** — Trust can function as stake/resource.
- **H-17-007** — Use No-Good Choice to force sacrifice.
- **H-17-008** — Objectives should shift after major reveal.
- **H-17-009** — Conflict sources: person / secret / time / system / self / relationship.
- **H-17-010** — Opposing characters need rational wants.
- **H-17-011** — Antagonist adapts to protagonist action.
- **H-17-012** — Protagonist errors come from flaw or incomplete information, not stupidity.
- **H-17-013** — Use Success With Cost.
- **H-17-014** — Use Failure With Value.
- **H-17-015** — Avoid reset outcomes.
- **H-17-016** — Track Resource Ladder as leverage changes.
- **H-17-017** — Pressure Triangle can combine incompatible pressures around choice.
- **H-17-018** — Escalate across arcs, not only scenes.
- **H-17-019** — Long-series stakes may deepen personal→relationship→identity→system→moral.
- **H-17-020** — Point of no return often belongs around 25–40%, adapted to story.
- **H-17-021** — Midpoint combines reveal + pressure.
- **H-17-022** — 75% phase should produce meaningful loss/crash.
- **H-17-023** — Ask what became harder because of what happened.
