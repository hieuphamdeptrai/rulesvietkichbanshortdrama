# v1.4 — HOOK & CLIFFHANGER ENGINE

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/03-twist-hook-cliff.md`

## Frozen rules
- **H-14-001** — Hook normally operates in first 3–5 seconds.
- **H-14-002** — Cliff normally operates in final 5–10 seconds.
- **H-14-003** — Use Hook→Promise→Progress→Cliff.
- **H-14-004** — Hook presents anomaly or specific question, not shock alone.
- **H-14-005** — Hook families: Impossible / Danger / Contradiction / Secret / Outcome-first.
- **H-14-006** — Specific curiosity is stronger than generic suspense.
- **H-14-007** — Rehook roughly every 15–25 seconds when useful.
- **H-14-008** — Do not force rehook if it creates artificial beat.
- **H-14-009** — Cliff types: Identity / Impossible / Betrayal / Confession / Evidence / Choice / Consequence / Reframe / Visual / Deadline.
- **H-14-010** — Cliff must be earned.
- **H-14-011** — Cliff must be consequential.
- **H-14-012** — Cut before processing only after real state change.
- **H-14-013** — Answer cliff enough before handing off to bigger/deeper question.
- **H-14-014** — No reset cliff.
- **H-14-015** — No fake-death spam.
- **H-14-016** — Do not repeat identical cliff mechanism; rotate form/intensity.
- **H-14-017** — Use Bridge Hook to connect prior payoff directly into new pursuit.
- **H-14-018** — Use Three-Episode Chain so consecutive cliff/reward structures build instead of restart.
- **H-14-019** — Hook Score max10.
- **H-14-020** — Cliff Score max12.
- **H-14-021** — Do not end on complete relief without forward pull when series still requires momentum.
- **H-14-022** — Hook asks what is happening; cliff asks where it leads.
