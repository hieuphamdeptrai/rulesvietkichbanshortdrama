# v3.2 — CONTINUITY & CANON INTEGRITY ENGINE

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/10-continuity-canon.md`

## Frozen rules
- **H-32-001** — Protect story memory across series→episode→scene→shot.
- **H-32-002** — Continuity layers: Canon / Timeline / Knowledge / Character / Relationship / Prop / Physical / Spatial / Visual.
- **H-32-003** — Maintain CANON.md.
- **H-32-004** — Use stable Canon IDs such as WOR/CHA/REL/TIM/OBJ/LOC/TRU.
- **H-32-005** — Canon statuses OPEN/PROVISIONAL/LOCKED/RETIRED.
- **H-32-006** — Distinguish Hard Canon vs Soft Canon.
- **H-32-007** — Track State Before/After.
- **H-32-008** — Track State Diff.
- **H-32-009** — Maintain True Timeline separately from Audience Timeline.
- **H-32-010** — Use timeline anchors/story days/travel/age checks.
- **H-32-011** — Knowledge states UNKNOWN / SUSPECTS / PARTIAL / KNOWS / FALSE BELIEF.
- **H-32-012** — Every knowledge transition needs source; no knowledge teleport.
- **H-32-013** — Track audience knowledge separately.
- **H-32-014** — Track audience false-belief evolution.
- **H-32-015** — Carry character physical state forward.
- **H-32-016** — Carry character emotional state forward.
- **H-32-017** — Emotional decay/masking is allowed when explained.
- **H-32-018** — No unexplained emotional reset.
- **H-32-019** — Relationship ledger: Trust/Power/Love/Fear/Debt/Secret.
- **H-32-020** — Relationship change requires event-backed cause.
- **H-32-021** — Prop ledger: owner/holder/location/condition/meaning/last/next.
- **H-32-022** — Track injury state.
- **H-32-023** — Track costume state.
- **H-32-024** — Track damaged variants.
- **H-32-025** — Location ledger includes layout/entrances/key features.
- **H-32-026** — Maintain spatial map when scene requires it.
- **H-32-027** — Protect 180°/axis/hand/eyeline/blocking continuity when production-critical.
- **H-32-028** — Use Shot Families.
- **H-32-029** — Use Master Frame.
- **H-32-030** — Use Scene Anchor.
- **H-32-031** — Use Change-Only Prompting for continuity-sensitive generation.
- **H-32-032** — Use One-Change principle when practical.
- **H-32-033** — Track shot start/end state.
- **H-32-034** — Use overlap/bridge between shots.
- **H-32-035** — Intentional discontinuity must be tagged.
- **H-32-036** — Narrative continuity outranks cosmetic perfection.
- **H-32-037** — Use local/episodic/global continuity windows.
- **H-32-038** — Use scene snapshots and deltas.
- **H-32-039** — Memory transaction: READ→APPLY→VALIDATE→COMMIT.
- **H-32-040** — Support rollback after invalid rewrite.
- **H-32-041** — Rewrite invalidates affected downstream state.
- **H-32-042** — Handle flashback explicitly.
- **H-32-043** — Handle Memory POV explicitly.
- **H-32-044** — Handle dream/time jump explicitly.
- **H-32-045** — Track world state.
- **H-32-046** — Track aliases/identity changes.
- **H-32-047** — Track dead/alive ledger.
- **H-32-048** — Maintain evidence/message/claim ledgers when relevant.
- **H-32-049** — Spoken claim is not automatically truth.
- **H-32-050** — A liar must remember cover story.
- **H-32-051** — Maintain POV ledger.
- **H-32-052** — Production Continuity Risk: LOW/MED/HIGH/CRITICAL.
- **H-32-053** — High-risk scene requires stronger anchors/references.
- **H-32-054** — Version production assets/references.
- **H-32-055** — Track continuity debt.
- **H-32-056** — Prefer smallest continuity patch.
- **H-32-057** — Audit Story/Episode/Scene/Shot at adaptive depth.
- **H-32-058** — Continuity score max20.
- **H-32-059** — Standard flags include CANON_CONFLICT.
- **H-32-060** — Standard flags include TIMELINE_CONFLICT.
- **H-32-061** — Standard flags include KNOWLEDGE_ERROR.
- **H-32-062** — Standard flags include PROP_TELEPORT.
- **H-32-063** — Standard flags include PHYSICAL_RESET / EMOTIONAL_RESET / RELATIONSHIP_RESET.
- **H-32-064** — Standard flags include SPATIAL_BREAK / VISUAL_DRIFT / REFERENCE_VERSION_MISMATCH / CLAIM_CONTRADICTION.
- **H-32-065** — Production Lock requires zero critical continuity errors.
- **H-32-066** — Episode snapshot feeds next episode.
- **H-32-067** — Run global audits around 5–10 episode windows/arc/midpoint/finale as needed.
- **H-32-068** — Use relevance filter to load only continuity facts needed now.
- **H-32-069** — Generate shots from same Scene Anchor, not memory of prior prompt.
