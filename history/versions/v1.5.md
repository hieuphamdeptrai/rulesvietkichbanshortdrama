# v1.5 — CHARACTER SECRET & SUSPICION ENGINE

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/04-character-relationship.md`

## Frozen rules
- **H-15-001** — Treat characters as Information Containers with asymmetrical access to truth.
- **H-15-002** — Character core: Public Face / Stated Want / Real Want / Secret / Fear / Breaking Point.
- **H-15-003** — Secret types: Identity / Action / Knowledge / Motive / Relationship.
- **H-15-004** — Secret→behavior→audience hypothesis.
- **H-15-005** — Secret must affect visible choices.
- **H-15-006** — Suspicion = Evidence + Missing Context.
- **H-15-007** — Suspect model: Motive + Means + Opportunity + Secret.
- **H-15-008** — Use roughly 3–5 meaningful suspects only when mystery benefits.
- **H-15-009** — Use Knowledge Leak as suspicion mechanism.
- **H-15-010** — Use Overreaction as suspicion mechanism.
- **H-15-011** — Use Underreaction as suspicion mechanism.
- **H-15-012** — Use Wrong Question as suspicion mechanism.
- **H-15-013** — Build secret collision/network.
- **H-15-014** — Track trust conceptually -5..+5 when useful.
- **H-15-015** — Establish Trust Deposit before high-impact betrayal.
- **H-15-016** — Use Partial Loyalty / Loyalty Hierarchy rather than binary loyal/traitor.
- **H-15-017** — Establish behavioral baseline before suspicious deviation.
- **H-15-018** — Lie engine: Direct Lie / Half Truth / Misleading Truth / Omission / Self-Deception.
- **H-15-019** — Track Secret Cost.
- **H-15-020** — Track Reveal Cost.
- **H-15-021** — Run Why-Not-Tell test.
- **H-15-022** — If safe explanation solves everything, secrecy is weak.
- **H-15-023** — Use suspicion rotation/transfer/exoneration/false exoneration.
- **H-15-024** — Suspicious behavior should become logical once truth is known.
