# v3.9 — STORY OBSERVABILITY, DIAGNOSTICS & HEALTH DASHBOARD ENGINE

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/13-lint-planning-observability.md`

## Frozen rules
- **H-39-001** — Observability tracks whole-system health/trends, not just scores or lint errors.
- **H-39-002** — Dashboard answers what is healthy.
- **H-39-003** — Dashboard answers what is decaying.
- **H-39-004** — Dashboard answers what should be fixed next.
- **H-39-005** — Health domains: Curiosity / Causality / Character / Relationship / Mystery / Escalation / Payoff / Continuity / Production / System.
- **H-39-006** — Health states: GREEN / YELLOW / ORANGE / RED.
- **H-39-007** — Trend states: IMPROVING / STABLE / DECLINING / VOLATILE.
- **H-39-008** — Health combines current level + trend + risk.
- **H-39-009** — Each signal stores current value/trend/threshold/confidence/source/why it matters.
- **H-39-010** — Track Primary Question Clarity.
- **H-39-011** — Track Question Progress.
- **H-39-012** — Track Next-Episode Desire.
- **H-39-013** — Track Theory Movement.
- **H-39-014** — Track Rehook Density.
- **H-39-015** — Track Cliff Variety.
- **H-39-016** — Track Reward Rate.
- **H-39-017** — Track question opened/last progress/age/priority.
- **H-39-018** — Question staleness is time since meaningful progress, not age alone.
- **H-39-019** — Question heat: HOT / WARM / COOL / DORMANT.
- **H-39-020** — Flag unintended core mystery dormancy.
- **H-39-021** — Track theory diversity/monopoly/volatility.
- **H-39-022** — Character health: agency/objective movement/decision impact/arc progress/emotional relevance/functional presence.
- **H-39-023** — Major character can be stagnant while physically present.
- **H-39-024** — Track Character Heat Map when useful.
- **H-39-025** — Relationship health: trust/power/dependency/emotion/conflict variety/payoff.
- **H-39-026** — Detect static relationship.
- **H-39-027** — Detect oscillation loop that moves but does not progress.
- **H-39-028** — Mystery health: status/age/last progress/clue count/theory/payoff readiness/memory risk.
- **H-39-029** — Track Mystery Debt dashboard.
- **H-39-030** — Payoff readiness: UNDERSET / READY / OVERSET / STALE.
- **H-39-031** — Detect payoff overexposure.
- **H-39-032** — Track setup memory health.
- **H-39-033** — Escalation health across Danger/Cost/Time/Relationship/Moral/Information.
- **H-39-034** — Detect escalation plateau.
- **H-39-035** — Detect escalation inflation.
- **H-39-036** — Causality health: event dependency/protagonist agency/antagonist adaptation/coincidence/success-with-cost/consequence persistence.
- **H-39-037** — Detect AND-THEN causality fragmentation.
- **H-39-038** — Use agency ratio conceptually, not as rigid metric.
- **H-39-039** — Continuity health aggregates canon/knowledge/timeline/prop/visual risks.
- **H-39-040** — Production health tracks high-risk scenes/missing assets/location/cast/VFX/stale packs/continuity tasks.
- **H-39-041** — System health tracks critical issues/stale artifacts/stale memory/branch debt/decision debt/blockers/pending sync/broken refs.
- **H-39-042** — Default Master Dashboard shows compact domain status + bottleneck + critical issues.
- **H-39-043** — Surface at most top 3 priority problems by default.
- **H-39-044** — Priority concept: Severity × Trend × Impact × Dependency Reach × Immediacy.
- **H-39-045** — Diagnose before mutating.
- **H-39-046** — Diagnostic cascade: Signal→Hypotheses→Evidence→Root Cause Candidate→Repair Route.
- **H-39-047** — Diagnostic confidence: HIGH / MEDIUM / LOW.
- **H-39-048** — Use multiple independent signals for strong diagnosis.
- **H-39-049** — Trend windows: short 2–3 episodes / arc 5–10 / series.
- **H-39-050** — Function-aware health avoids flagging intentional quiet episodes.
- **H-39-051** — Compare actual metric with intended episode/genre/format profile.
- **H-39-052** — Arc Health Card summarizes question/progress/escalation/character/payoff/health.
- **H-39-053** — Episode Health Card summarizes score/function/state change/reward/cliff/risks/dependencies.
- **H-39-054** — Character Health Card summarizes agency/arc/relationship/mystery relevance/last major decision/risk.
- **H-39-055** — Mystery Health Card summarizes status/heat/theory/last-next progress/payoff/memory.
- **H-39-056** — Track Open Loop dashboard.
- **H-39-057** — Track Promise dashboard.
- **H-39-058** — Track Decision/Branch/Artifact/Memory health.
- **H-39-059** — Save health snapshots at milestones.
- **H-39-060** — Compare before/after mutation.
- **H-39-061** — Detect quality regression even without lint violation.
- **H-39-062** — Define project-specific Story Quality Objectives where useful.
- **H-39-063** — SLO breach is warning, not universal law.
- **H-39-064** — Breather episode can intentionally lower tension but should resume momentum.
- **H-39-065** — Track surprise/cliff/writer trust/frustration/confusion/cognitive load/emotional variation/theme/signature health.
- **H-39-066** — Detect Signature Decay.
- **H-39-067** — Production observability tracks readiness/hotspots/cost curve/reuse.
- **H-39-068** — System self-health detects overprocessing.
- **H-39-069** — Detect REPAIR_LOOP.
- **H-39-070** — Detect EXPLORATION_STALL.
- **H-39-071** — Detect analysis paralysis and converge when more analysis adds little value.
- **H-39-072** — Default one master dashboard; detailed reports only when needed.
- **H-39-073** — Critical weakness overrides aggregate average.
- **H-39-074** — Health confidence must reflect incomplete data.
- **H-39-075** — Every signal has source.
- **H-39-076** — Conflicting signals trigger diagnosis rather than blind averaging.
- **H-39-077** — Human qualitative feedback can be signal.
- **H-39-078** — Alerts: INFO / WATCH / WARNING / CRITICAL.
- **H-39-079** — Use early warning before full violation.
- **H-39-080** — Predictive risk is heuristic, not certainty.
- **H-39-081** — Detect payoff congestion.
- **H-39-082** — Detect reveal collision.
- **H-39-083** — Inspect upcoming 3–5 episode risk window from locked plans.
- **H-39-084** — Track development confidence LOCKED/STABLE/PROVISIONAL/OPEN.
- **H-39-085** — Track Rework Risk from low confidence + high downstream cost.
- **H-39-086** — /status = workflow state; /health = health; /diagnose = root-cause analysis.
- **H-39-087** — Observability feeds Scheduler/Branching/Mutation/Red-Team/Memory.
- **H-39-088** — Flags include HEALTH_SIGNAL_STALE / NEGATIVE_TREND_IGNORED / DASHBOARD_SOURCE_CONFLICT / PAYOFF_CONGESTION / CHARACTER_STAGNATION / SIGNATURE_DECAY / REPAIR_LOOP / EXPLORATION_STALL.
- **H-39-089** — Do not optimize metrics instead of viewer experience.
- **H-39-090** — Preserve healthy systems during repair.
- **H-39-091** — Stop optimization when primary promises are healthy enough to advance.
