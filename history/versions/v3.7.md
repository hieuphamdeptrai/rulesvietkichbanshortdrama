# v3.7 — CREATIVE BRANCHING, EXPERIMENT & SELECTION ENGINE

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/14-branching-rescue.md`

## Frozen rules
- **H-37-001** — Use controlled experiments to avoid first-idea lock-in while protecting canon.
- **H-37-002** — Branch = creative hypothesis, not alternative wording.
- **H-37-003** — Branch mainly high-impact/high-uncertainty premise/truth/antagonist/relationship/midpoint/reframe/arc solution/twist/hook/cliff.
- **H-37-004** — Branch scales: Micro / Episode / Arc / Core.
- **H-37-005** — Limit branch count; branch only when expected value justifies cost.
- **H-37-006** — Branches differ on at least one major structural axis.
- **H-37-007** — Use orthogonal branching to test one axis when diagnosing.
- **H-37-008** — Combining good pieces creates a new branch and requires validation.
- **H-37-009** — No Frankenstein merge.
- **H-37-010** — Lifecycle: SEED / DEVELOPING / TESTABLE / SELECTED / REJECTED / ARCHIVED / MERGED.
- **H-37-011** — Use stable branch IDs.
- **H-37-012** — Maintain branch manifest.
- **H-37-013** — Branch facts are isolated from MAIN.
- **H-37-014** — No branch fact becomes MAIN canon before selection/merge.
- **H-37-015** — Creation modes: FORK / SEED / REBUILD.
- **H-37-016** — Define Shared Locks before experiment.
- **H-37-017** — Define Branch Variables before experiment.
- **H-37-018** — Every experiment has one clear question.
- **H-37-019** — Experiment Card includes current problem/success criteria/tests.
- **H-37-020** — Control variables so comparison teaches something.
- **H-37-021** — Use baseline when needed.
- **H-37-022** — Progressive investment levels 0–5.
- **H-37-023** — Cheap tests first.
- **H-37-024** — Use stage-gate survivor process.
- **H-37-025** — Branch Card records core change/preserved elements/story logic/audience effect/character effect/mystery effect/payoff effect/production effect/setups/broken setups/ripple/risk.
- **H-37-026** — Compare audience experience, not plot summary only.
- **H-37-027** — Compare theory shape.
- **H-37-028** — Track ripple cost.
- **H-37-029** — Track setup cost.
- **H-37-030** — Track explanation cost.
- **H-37-031** — Track cognitive complexity.
- **H-37-032** — Track production cost.
- **H-37-033** — Track emotional gain.
- **H-37-034** — Core branch metrics: curiosity / logic / character / emotion / payoff / freshness / series fuel / production / simplicity / rewatch.
- **H-37-035** — Critical integrity fail disqualifies branch unless experiment explicitly unlocks that constraint.
- **H-37-036** — Top branches run Simulation.
- **H-37-037** — Top branches run Red-Team.
- **H-37-038** — Top branches run Linter.
- **H-37-039** — Compare under equal conditions/depth.
- **H-37-040** — Use comparison matrix plus narrative tradeoff.
- **H-37-041** — Do not select by total score alone.
- **H-37-042** — Selection considers project priority.
- **H-37-043** — Selection considers genre weights.
- **H-37-044** — Selection considers current bottleneck.
- **H-37-045** — Selection considers production constraint.
- **H-37-046** — Outcomes: clear winner / tradeoff / no winner.
- **H-37-047** — Do not force a winner.
- **H-37-048** — Major selection becomes Decision.
- **H-37-049** — Winner does not auto-merge.
- **H-37-050** — Merge pipeline: freeze→choose→validate→merge plan→apply→invalidate→regression→update MAIN→archive.
- **H-37-051** — Merge conflict with Locked Canon requires reject or explicit unlock.
- **H-37-052** — Archive rejected branches with why rejected.
- **H-37-053** — Rejected branch may donate reusable idea to Idea Bank but remains non-canon.
- **H-37-054** — Use delta-based branch storage where practical.
- **H-37-055** — Materialize branch view from base + delta.
- **H-37-056** — Detect stale branch base.
- **H-37-057** — Rebase only with conflict detection.
- **H-37-058** — Avoid combinatorial explosion.
- **H-37-059** — Use staged experiments rather than multiplying all axes.
- **H-37-060** — Track Decision Debt.
- **H-37-061** — High-level choices converge before downstream lock.
- **H-37-062** — Record divergence point.
- **H-37-063** — Branches may reconverge only if output states actually match.
- **H-37-064** — Branch levels STORY / SCREENPLAY / PRODUCTION remain separate.
- **H-37-065** — Use blind evaluation when possible.
- **H-37-066** — Multi-judge disagreement should be reported, not blindly averaged.
- **H-37-067** — Preserve Pareto tradeoffs when no dominant winner.
- **H-37-068** — Stop experiment when winner clear or remaining uncertainty low-impact.
- **H-37-069** — Use inversion/early-reveal/simplification/constraint/character-first/payoff-first/mystery-first search strategies when relevant.
- **H-37-070** — Flags: BRANCH_LEAK / STALE_BRANCH_BASE / UNCONTROLLED_VARIABLES / FALSE_DIVERSITY / MERGE_CONFLICT / SELECTED_BRANCH_NOT_VALIDATED / DECISION_DEBT.
- **H-37-071** — Divergence creates options; convergence creates story.
