# v3.5 — STORY LINTER & AUTOMATED VALIDATION ENGINE

**Frozen design history.** Runtime consolidation does not delete these rules.

**Current operational owner:** `modules/13-lint-planning-observability.md`

## Frozen rules
- **H-35-001** — Linter catches structural/mechanical violations; Red-Team judges narrative quality; Scoring measures strength.
- **H-35-002** — Pipeline: LOAD PROJECT→VALIDATE SCHEMA→RESOLVE REFERENCES→BUILD GRAPH→RUN RULE SETS→CLASSIFY ISSUES→DEDUPLICATE→IMPACT ANALYSIS→REPORT→OPTIONAL SAFE AUTOFIX→REVALIDATE.
- **H-35-003** — Validation layers: Data / Reference / State / Canon / Causality / Story Structure / Repetition-Health / Production.
- **H-35-004** — Modes: QUICK / EPISODE / ARC / FULL PROJECT.
- **H-35-005** — Prefer incremental validation on affected graph.
- **H-35-006** — Results: PASS / WARN / FAIL / CRITICAL / SKIPPED.
- **H-35-007** — Severity: CRITICAL / MAJOR / MODERATE / MINOR.
- **H-35-008** — Every issue includes rule ID/entity/severity/evidence/impact/dependencies/repair route.
- **H-35-009** — Data checks: missing required field / invalid enum/status/version / duplicate ID.
- **H-35-010** — Reference checks: broken / retired / wrong branch / superseded / orphan.
- **H-35-011** — Canon checks: direct conflict / draft overrides locked canon / retired fact leak / unknown treated true / world-rule violation.
- **H-35-012** — State checks: unexplained jump/reset / output-input mismatch / uncommitted change.
- **H-35-013** — Knowledge checks: teleport / forgotten knowledge / false belief not updated / incomplete propagation / writer-truth leak / impossible claim.
- **H-35-014** — Timeline checks: effect before cause / double location / impossible travel / age conflict / deadline miscount / flashback mismatch.
- **H-35-015** — Causality checks: causeless major event / convenient interruption / coincidence over-budget / missing consequence / action no plot effect / antagonist non-response.
- **H-35-016** — Mystery checks: missing truth/payoff / staleness / question overload or monopoly / answer no story change / missing handoff.
- **H-35-017** — Clue checks: clue after reveal / clue without purpose / payoff without clue / too-late footprints / memory decay / invalid red herring / contradiction with truth.
- **H-35-018** — Payoff checks: unpaid setup / payoff without setup / stale setup / broken promise / deleted payoff / finale debt.
- **H-35-019** — Episode checks: no primary question / no state change / no objective / no reward / fake or meaningless cliff / cliff repetition / function repetition / AND-THEN chain / neighbor mismatch / recap overload / duration-payload mismatch.
- **H-35-020** — Arc checks: no arc question / no escalation / flat answer-handoff / stall / weak midpoint / exit same as entry.
- **H-35-021** — Character checks: missing want / action without motive / personality flip / secret no behavior / deletable character / passive protagonist / passive villain.
- **H-35-022** — Relationship checks: reset / trust jump / unearned betrayal / easy reconciliation / static relationship / miscommunication-only conflict.
- **H-35-023** — Prop/continuity checks: teleport / condition reset / duplicate unique prop / disappearance / knowledge error / physical-costume-location-reference-hand mismatch.
- **H-35-024** — Repetition checks: pattern/cliff/suspect/info/emotion/location/conflict saturation.
- **H-35-025** — Repetition is a flag, not automatic fail.
- **H-35-026** — Retention checks: no perceived progress / stale question / reward drought / shock overload / post-payoff drop.
- **H-35-027** — Format/production/memory checks integrate v3.1/v3.2/v3.3.
- **H-35-028** — Use lint-config with LIGHT/STANDARD/STRICT/PRODUCTION profiles.
- **H-35-029** — Thresholds adapt by genre/format/state.
- **H-35-030** — Intentional rule break uses explicit exception/PASS_EXCEPTION.
- **H-35-031** — No silent rule disable.
- **H-35-032** — Group issues by root cause to prevent warning spam.
- **H-35-033** — Report top actionable issues first.
- **H-35-034** — Linter is not a creative fixer.
- **H-35-035** — Safe autofix only deterministic/mechanical changes.
- **H-35-036** — Creative canon autofix is forbidden.
- **H-35-037** — Lock gates run appropriate lint profile.
- **H-35-038** — Critical blocks lock.
- **H-35-039** — Major normally blocks lock unless explicit approved exception.
- **H-35-040** — Use pre-commit lint.
- **H-35-041** — Use post-commit validation.
- **H-35-042** — Use regression lint.
- **H-35-043** — Use diff-aware lint.
- **H-35-044** — Introduce Story Tests: invariant / transition / payoff / continuity / genre / production.
- **H-35-045** — Hard tests and soft tests are distinct.
- **H-35-046** — Locked creative decisions can become project-specific assertions.
- **H-35-047** — Story CI can automate structural tests later.
- **H-35-048** — Every warning needs exact evidence.
- **H-35-049** — Missing evidence yields UNKNOWN/INSUFFICIENT_DATA, not invention.
- **H-35-050** — Severity is salience- and meaning-aware.
- **H-35-051** — Deterministic rules and heuristic rules are distinct.
- **H-35-052** — Heuristic warning needs stronger evidence than vague impression.
- **H-35-053** — Passing lint only means no known structural violation.
- **H-35-054** — Fix upstream root cause before downstream symptom.
