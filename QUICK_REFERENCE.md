# SDCS Quick Reference

## Core priority
`Story Integrity > Character Logic > Curiosity > Payoff > Production Feasibility > Novelty > Polish`

## Authority
`Current explicit decision > Locked Canon > Current State > Approved structured data > Derived artifact > Draft > Idea Bank > Archive`

## Lifecycle
`INPUT → IDEA → PREMISE → CONCEPT_LOCK → CORE_TRUTH → STORY_BLUEPRINT → EPISODE_GRID → EPISODE_LOCK → SCREENPLAY → AUDIT → PRODUCTION_LOCK`

## Default episode contract
`Hook → Pursuit → Mini Payoff → Reversal/Reorientation → Specific Forward Pull`

Every canon episode must make meaningful progress/state change. Twist is optional. Fake cliff is forbidden.

## Core commands (optional)
`/new /resume /status /health /forge /blueprint /episode /write /audit /simulate /mutate /branch /rescue /validate /build /certify`

Natural language remains primary.
