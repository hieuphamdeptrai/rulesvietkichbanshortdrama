# Story Memory, Context Retrieval & Compression
**Origin:** v3.3

- Repo = long-term memory; context = working memory.
- Authority: Locked Canon > Current State > Locked Blueprint > Episode Card > Draft > Idea Bank.
- Memory item carries ID/TYPE/VALUE/STATUS/SOURCE/SCOPE/LAST UPDATED/DEPENDENCIES.
- Scope GLOBAL/ARC/EPISODE/SCENE/SHOT; class CANON/STATE/DECISION/CLUE/PROMISE/ISSUE/IDEA/RETIRED/PRODUCTION.
- Current state and event history are distinct.
- Rejected ideas/Negative Canon remain searchable but inactive.
- Retrieve by task dependency, not full repo. Episode work uses Previous/Current/Next or N-1/N/N+1.
- Context Pack includes project core, current arc/episode, relevant characters/audience/continuity/constraints.
- Lossless-required: truth/timeline/knowledge/prop/world; lossy summary allowed elsewhere.
- Writer/Audience/Character perspectives remain separate.
- Summaries are VERIFIED/UNVERIFIED/STALE and version-bound.
- CURRENT_STATE and BOOTSTRAP refresh after relevant commits.
- Role firewalls prevent Writer Truth leak and archive contamination.
- Exactness EXACT/SEMANTIC/FLEXIBLE; salience CRITICAL/HIGH/MED/LOW.
- Compression C0 RAW/C1 detailed/C2 structured/C3 executive; causal summary Event→Meaning→Change.
- Unknown is valid; assumptions are not canon.
- Project must outlive chat and resume from repo.
