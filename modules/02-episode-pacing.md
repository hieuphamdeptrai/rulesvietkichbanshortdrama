# Episode, Pacing & Retention Engine
**Origins:** v1.2, v1.9

## Episode contract
Function / Input State / Previous Cliff / Primary Question / Objective / Obstacle / Clue-Progress / Reward / Reversal / Output State Change / Cliff / Next Handoff.

- Typical 45–90s episode may use Cold Open→Orientation→Pursuit→Mini Payoff→Reversal→Cliff, adapted by duration.
- One Primary Episode Question. First 5–10s establishes episode promise.
- Every scene performs at least two functions among plot/character/clue/tension.
- Dialogue has surface + subtext and pressure: A wants / B wants / hidden intent / leverage.
- Object curiosity can use Plant→Reappear→Change Meaning→Payoff.
- Use Visual Question, Dramatic Irony and Mini Loop to reduce exposition and provide local reward.
- Every canon episode changes Knowledge, Trust, Danger, Objective, Power or Relationship.
- Short-form guideline: meaningful movement roughly every 8–15s; rehook roughly 15–25s when useful.
- Start late, leave early; one major idea at a time; give large reveals/emotional choices processing room.
- Resolve enough of prior cliff early before replacing it with a new promise.
- First 3 episodes establish premise/core mystery, prove engine, and provide real reward.
- Removal Test / Drop Detector: if episode can disappear without consequence, redesign/remove.
- Pacing is perceived progress, not permanent speed or twist density.
- Retention chain: Hook→Q→Action→Clue→Theory→Complication→Reveal→NewQ→Cliff.
