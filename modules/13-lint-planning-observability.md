# Linter, Dependency Scheduler & Observability
**Origins:** v3.5, v3.8, v3.9

## Linter
- Linter catches structural/mechanical violations; Red-Team judges narrative quality; scoring measures strength.
- Pipeline: schema→refs→graph→rules→severity→dedupe→impact→report→safe mechanical fix→revalidate.
- Modes Quick/Episode/Arc/Full; incremental first.
- Issue contains Rule ID, entity/location, severity, evidence, impact, dependencies and repair route.
- Check data/ref/canon/state/knowledge/timeline/causality/mystery/clue/payoff/episode/arc/character/relationship/prop/continuity/repetition/retention/format/production/memory.
- State-aware thresholds; intentional exceptions explicit; creative canon is never auto-fixed.
- Group symptoms by root cause; Critical blocks lock.
- Story Tests can assert invariants/transitions/payoffs/continuity/production/project-specific contracts.

## Scheduler
- Dependency types Story Logic/Canon/Information/Character/Artifact/Production/Approval/Validation.
- Severity BLOCKING/HIGH/MEDIUM/LOW; task READY only when blockers satisfied.
- Prioritize Critical Path and Unlock Value, not easiest task.
- Track setup/payoff deadlines, decision windows/debt, assumptions, cycles, placeholders, production readiness and safe parallel work.
- Upstream change invalidates downstream and creates rebuild task plan.
- Next Best Action maximizes unlock/quality/urgency while minimizing waste/rework.

## Observability
- Health domains Curiosity/Causality/Character/Relationship/Mystery/Escalation/Payoff/Continuity/Production/System.
- Status GREEN/YELLOW/ORANGE/RED + trend IMPROVING/STABLE/DECLINING/VOLATILE + confidence/source.
- Default dashboard surfaces at most top 3 priorities.
- Diagnose Signal→Hypotheses→Evidence→Root Cause→Repair Route.
- Watch question staleness, theory monopoly, character/relationship stagnation, payoff readiness/congestion, escalation plateau/inflation, causality/agency, writer trust, cognitive load, signature decay and system repair/branch loops.
- Preserve green strengths; stop optimizing when healthy enough to advance.
