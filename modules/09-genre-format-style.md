# Genre, Format, Style & Creative Identity
**Origins:** v3.1, v4.0

## Genre/format
- Invariants stay stable; genre/format adjusts weights/cadence/thresholds.
- GENRE_PROFILE: Primary, Secondary, Tone, Audience Promise, Primary Curiosity Engine, Emotional Engine, Forbidden Drift.
- Primary genre wins conflicts; fusion requires causal interaction.
- Tone is separate from genre.
- Duration 30/45/60/90/120s+ changes payload/state-change capacity, not dialogue padding.
- Series length: Mini6–12 / Short13–20 / Standard21–35 / Long36–50 / Extended50+.
- Scale arc count, reveal/twist/cliff heat and debt to actual length.
- World Layer is not Story Engine.

## Style
- Creative identity = Story Promise + Emotional Temperature + Voice + Rhythm + Visual Language + Motifs + Restraint + Signature.
- STYLE_PROFILE covers tone/dialogue/narration/emotion/realism/poetic/humor/violence/visual/motif/forbidden drift.
- Project voice ≠ character voice. Character voice comes from psychology, strategy and relationship/power context.
- Avoid catchphrase-only differentiation and generic AI polish/exposition.
- Narration has narrator/reliability/function and cannot patch plot holes.
- Visual grammar defines recurring framing/camera/composition/lighting/reveal logic, not a rigid shot list.
- Motif repeats only when meaning accumulates/changes.
- Style baseline can deviate intentionally for important moments; style itself can arc.
- Translation preserves power/intimacy/formality/subtext.
- Style cannot hide broken story logic and must remain scalable for production.
