# Creative Branching, Experiment & Story Rescue
**Origins:** v3.7, v4.1

## Branching
- Branch = creative hypothesis, not wording alternative.
- Use for high-impact/high-uncertainty premise/truth/antagonist/relationship/midpoint/ending/twist/hook/cliff decisions.
- Define Experiment Question, Shared Locks, Variables, Success Criteria and comparable depth.
- Branch lifecycle SEED/DEVELOPING/TESTABLE/SELECTED/REJECTED/ARCHIVED/MERGED; keep MAIN isolated.
- Progressive investment: one-line→card→arc implication→key beats→sample→full integration.
- Compare curiosity/logic/character/emotion/payoff/freshness/fuel/production/simplicity/rewatch plus ripple/setup/explanation/cognitive cost.
- Run Lint/Simulation/Red-Team on finalists under same constraints.
- Winner does not auto-merge; explicit Decision + Merge Plan + regression required.
- Combining pieces from branches creates a new branch.
- Track Decision Debt, stale base/rebase conflict and branch contamination.

## Rescue
- Preserve strengths first: MUST PRESERVE / PREFER PRESERVE / FREE TO CHANGE.
- Failure levels F1 Local/F2 Sequence/F3 Arc/F4 Character-Relationship/F5 Core/F6 Production-Locked.
- Diagnose root cause. Escalation ladder PATCH→REFRAME→RESTRUCTURE→REPLACE→ROLLBACK→UNLOCK.
- Use lowest intervention that restores function; prefer reframe over hard retcon.
- RED project health pauses normal downstream generation.
- Production-aware rescue may use re-edit/insert/reaction/audio/later scene/recontextualization before expensive reshoot.
- Patch accumulation means move upstream; failed repair rolls back before next attempt.
- Every major rescue gets postmortem and new guardrail/test if applicable.
