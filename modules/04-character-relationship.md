# Character, Secret, Suspicion & Relationship Engine
**Origins:** v1.5, v2.9

Character core: Public Face / Want / Need / Wound / False Belief / Fear / Loyalty / Secret / Contradiction / Strategy / Moral Boundary / Breaking Point / Arc End.

- Character = decision engine under pressure: Want→Pursue→Obstacle→Strategy→Flaw→Consequence→Choice→Change/double-down.
- Secrets types: Identity/Action/Knowledge/Motive/Relationship; secret must alter visible behavior and have cost.
- Run Why-Not-Tell test; if safe explanation solves everything, secrecy is weak.
- Suspicion = Evidence + Missing Context. Suspect model: Motive + Means + Opportunity + Secret.
- Establish baseline before Knowledge Leak / Overreaction / Underreaction / Wrong Question.
- Lie engine: Direct / Half Truth / Misleading Truth / Omission / Self-Deception.
- Use 3–5 meaningful suspects only when story benefits; rotate/exonerate/transfer suspicion with progress.
- Relationship Tension = Want Conflict + Secret + Dependency.
- Track Trust/Love/Fear/Respect/Debt/Power asymmetrically; A→B can differ from B→A.
- Betrayal needs Trust Deposit; recovery needs consequence/cost.
- Build leverage, shared history, shared secret, debt and secret collision into network.
- Supporting characters need unique function; merge/remove redundancy.
- Antagonist has rational goal/strategy/false belief and adapts; protagonist maintains agency.
- Character-driven twist/cliff/escalation/payoff preferred.
- Introduce via behavior under pressure, not biography dump.
- Romance-mystery fusion requires the romance and mystery to causally affect one another.
