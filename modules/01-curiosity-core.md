# Curiosity Core, Architecture, Patterns & Composition
**Origins:** v1.0, v1.1, v2.4, v2.5

- Retention comes from specific Information Gaps, evolving theories and consequences.
- Always leave at least one meaningful forward question while paying enough Curiosity Debt to preserve trust.
- Question Chain: Q1→A1/Q2→A2/Q3. Answer should deepen/reframe rather than reset.
- Mystery layers: Micro / Arc / Core. Keep one Primary Question dominant; avoid overload.
- Reveal types include Information / Identity / Motive / Meaning; rotate progression type.
- Curiosity Pulse: tension→reveal→brief relief→new problem.
- Arc curiosity: Question→Theory→Evidence→Answer→Reversal.
- Audience must have evidence to theorize; confusion is not curiosity.
- Pattern families: Impossible Fact, Identity, Information, Time, Object, Trust, Motive, Cause, Location, Relationship, Memory/Perception, System, Choice, Threat, Reveal/Solution, Meta.
- Pattern is mechanism, not beat or plot. Compose decision→consequence→next mechanism.
- Six functions: Hook / Clue / Suspicion / Escalation / Reveal / Cliff.
- Use BECAUSE/THEREFORE/BUT causal handoff; avoid AND-THEN chains.
- Question depth can move What→Who→How→Why→Meaning.
- Three-Value Test: curiosity + character + plot.
- Pattern Debt, Surprise Budget, Curiosity Portfolio and Q priority P1/P2/P3 help long series avoid repetition.
- Originality comes from familiar mechanism + specific character/motive/world + changed meaning, not random novelty.
- Golden Triangle: Curiosity + Causality + Character.

Historical detail remains authoritative in corresponding `history/versions/` files.
