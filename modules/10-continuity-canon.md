# Continuity & Canon Integrity
**Origin:** v3.2

Layers: Canon / Timeline / Knowledge / Character / Relationship / Prop / Physical / Spatial / Visual.

- Stable IDs and Hard/Soft Canon with OPEN/PROVISIONAL/LOCKED/RETIRED.
- State Before/After + State Diff; important changes reference source Event.
- True Timeline ≠ Audience Timeline; check story day, age, travel, deadline.
- Knowledge states UNKNOWN/SUSPECTS/PARTIAL/KNOWS/FALSE BELIEF; every transition needs source.
- Audience knowledge and false belief tracked separately.
- Character physical/emotional state persists; relationship ledger Trust/Power/Love/Fear/Debt/Secret; no unexplained reset.
- Prop ledger: owner/holder/location/condition/meaning/last/next.
- Track injuries/costumes/damaged variants and location layout/spatial/blocking/axis/eyeline.
- High-risk scenes use Master Frame / Scene Anchor; Change-Only / One-Change prompting is safer for AI continuity.
- Claim ≠ Truth; liar remembers cover story.
- Use READ→APPLY→VALIDATE→COMMIT transaction and rollback/invalidation.
- Production risk LOW/MED/HIGH/CRITICAL; zero critical continuity errors at Production Lock.
- Narrative continuity outranks cosmetic perfection, except when visual detail changes story meaning.
