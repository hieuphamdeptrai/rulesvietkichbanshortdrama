# Twist, Hook & Cliffhanger Engine
**Origins:** v1.3, v1.4

- Twist = Surprise + Inevitability + Consequence.
- Audience Belief→Contradiction→New Interpretation.
- Twist families: Identity / Motive / Relationship / Cause / Timeline / POV / Object / Meaning.
- Major twist normally needs 2–3 fair footprints; use double-meaning plant, reaction clue, absence clue, negative evidence.
- Prefer true fact + wrong inference. Red herring should have factual basis and ideally secondary payoff.
- No POV/camera cheating; False Reveal contains partial truth rather than arbitrary fabrication.
- Character-driven twist is preferred; simplest adequate explanation wins.
- Hook normally occupies first 3–5s: anomaly/specific question, not empty shock.
- Hook families: Impossible / Danger / Contradiction / Secret / Outcome-first.
- Cliff normally final 5–10s and must create a specific urgent consequence/question.
- Cliff families: Identity / Impossible / Betrayal / Confession / Evidence / Choice / Consequence / Reframe / Visual / Deadline.
- Cut before processing only after earned state change.
- Next episode resolves enough, then hands off to bigger/deeper question.
- Rotate cliff mechanisms/intensity; no fake reset/death spam.
- Hook asks “what is happening?”; cliff asks “where does this lead?”
