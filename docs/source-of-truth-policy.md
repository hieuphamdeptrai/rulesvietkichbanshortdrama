# Source of Truth Policy

Authority order:
1. Current explicit user/project decision.
2. Locked Canon.
3. Current authoritative State.
4. Approved structured project data/blueprint.
5. Derived artifacts.
6. Drafts.
7. Idea Bank.
8. Archived/retired/history.

A summary is a cache, not authority. A derived artifact never overrides its sources. Explicit user changes to locked material require unlock → impact/ripple analysis → update → invalidation → regression check.
