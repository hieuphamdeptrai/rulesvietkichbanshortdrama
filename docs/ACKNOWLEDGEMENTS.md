# Acknowledgements & External Research Notes

SDCS is independently designed and its frozen rule history remains authoritative.

For the 1.0.1 hardening pass, the public MIT-licensed repository
`Puhua-AI-Research/short-drama-skill` was reviewed as an external reference.

Conceptual lessons adopted in original SDCS form:
- explicit progressive disclosure through stage/task-specific reference loading;
- keeping creative state and production artifacts organized for resumability;
- separating emotional reward design from pure plot twist frequency;
- treating commercial checkpoints as an optional profile rather than universal story structure;
- scene boundary/keyframe metadata as a promising future AI-video continuity contract;
- tool honesty: failed or unexecuted media generation must never be reported as success.

No provider-specific scripts, sample scenes, or substantial source text are copied into SDCS.
