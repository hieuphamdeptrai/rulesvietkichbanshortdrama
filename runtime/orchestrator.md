# Master Orchestrator
1. Read project state/version/branch/authoritative source.
2. Interpret task/scope/user intent/output contract.
3. Check gate, blockers, dependencies, stale inputs.
4. Select one current bottleneck.
5. Assemble smallest complete context + minimum modules.
6. Execute appropriate mode.
7. Validate deterministic integrity first; deeper QA at milestone depth.
8. Commit only approved/validated changes.
9. Invalidate downstream artifacts/summaries/certifications.
10. Update state/decision/issue/bootstrap.
11. Return Next Best Action.

For local one-off work, do not force full-project bureaucracy.
