# Quality Gates
## Concept Lock
Premise engine, story lock, genre/format, protagonist relevance, viable truth space.
## Core Truth Lock
Writer truth, motive/meaning, why-now, why-protagonist, no critical contradiction.
## Blueprint Lock
Characters/relationships, arcs, mystery ladder, clue/payoff backbone, escalation, finale direction, lint pass.
## Episode Lock
Input state, primary question, objective, reward/progress, state change, forward pull, continuity/dependency pass.
## Screenplay Lock
Matches Episode Card, no knowledge/state drift, style pass, gate-appropriate QA.
## Production Lock
Approved script, continuity, critical refs/assets, future setup audit, zero critical blockers.
