# State Machine
`INPUT → IDEA → PREMISE → CONCEPT_LOCK → CORE_TRUTH → STORY_BLUEPRINT → EPISODE_GRID → EPISODE_LOCK → SCREENPLAY → AUDIT → PRODUCTION_LOCK`

Default: no skip. Prototype skip is NON-CANON. Downstream lock is invalid when blocking upstream dependency is OPEN/stale. Major upstream mutation invalidates affected downstream artifacts/certifications.
