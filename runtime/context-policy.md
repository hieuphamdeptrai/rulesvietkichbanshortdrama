# Context Policy
Repo = long-term memory. Context = task-specific working memory.

Default: SYSTEM → project BOOTSTRAP/STATE → task dependencies → relevant entities/modules. Episode tasks use N-1/N/N+1 plus arc/core dependencies.

Firewalls: Audience Simulator has no unreleased truth; Character POV has no unknown facts; archive/rejected branches excluded by default.

Lossless-required: truth, timeline, knowledge, prop, world. Compress prose, not logic.
