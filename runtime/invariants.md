# Runtime Invariants
1. Curiosity progresses; withholding without reward is not progress.
2. Character action is motivated by current want/fear/knowledge/loyalty/strategy.
3. Locked canon cannot change silently.
4. Truth, Belief, Knowledge, Claim and State remain distinct.
5. Major twist requires fair footprints and consequence.
6. Important setup requires payoff or explicit retirement.
7. State changes persist until another event changes them.
8. Audience simulator cannot see unreleased writer truth.
9. Derived artifacts never outrank source.
10. Historical rules may be consolidated but never silently lost.
